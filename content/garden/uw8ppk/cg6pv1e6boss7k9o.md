# 状态机
**核心思想：系统在任何时刻都处于一个状态，当发生某个事件时，会根据规则切换到另一个状态。**

三个核心要素：**状态，事件，状态转换**

优点：

+ **逻辑清晰**：每个状态负责自己的行为。
+ **容易维护**：新增状态或规则时影响较小。 
+ **避免非法操作**：例如未登录时不能退出登录，电梯开门时不能上行。 
+ **广泛应用**：游戏开发、UI 界面、网络协议、机器人控制、订单流程、工作流等。 

### 订单状态
```plain
待支付
   │ 支付成功
   ▼
待发货
   │ 商家发货
   ▼
运输中
   │ 用户签收
   ▼
已完成
```

| 当前状态 | 事件 | 下一个状态 |
| --- | --- | --- |
| 待支付 | 支付成功 | 待发货 |
| 待支付 | 超时 | 已取消 |
| 待发货 | 发货 | 运输中 |
| 运输中 | 签收 | 已完成 |
