# 内存管理
![画板](/images/yuque/9f64e16ef7dfecc5.jpg)

物理地址：两个程序引用绝对物理地址是无法同时运行的

虚拟地址：把进程所使用的地址隔离开，为每个进程分配一个虚拟地址

**分段：**程序是由若干个逻辑分段组成的，如可由代码分段、数据分段、栈段、堆段组成。**不同的段是有不同的属性的，所以就用分段（**_**Segmentation**_**）的形式把这些段分离出来。**

解决内存外部碎片：内存交换（将程序占用的内存先写到硬盘上，再从硬盘重新读回，读回时重新找位置，最好是和之前的程序内存连续。  内存交换会产生性能瓶颈，导致机器卡顿

**分页：****分页是把整个虚拟和物理内存空间切成一段段固定尺寸的大小**

虚拟地址与物理地址之间通过页表映射

# 虚拟化
## 调度
### 进程调度
FIFO（先进先出） -> SJF（最短任务优先） -> STCF（最短完成时间优先）

### 多级反馈队列
MLFQ

+ 规则一：A的优先级 > B的优先级，运行A（不运行B）
+ 规则二：A的优先级 = B的优先级，轮转运行
+ 规则三：工作进入系统时，放入最高优先级
+ 规则四：工作用完了在某一层中的时间配额（无论中间主动放弃多少次），就降低优先级
+ 规则五：经过一段时间S，就将系统中的所有工作重新加入最高优先级队列

### 比例份额
彩票机制（没有最优的分配方案）

步长调度 每个工作有自己的步长，与票值成反比。

票值： A 100、B 50、C 250  （通过一个大数除以票值，比如 10000）

步长： A 100、B 200、C 40

刚开始：所有进程都可能被选择执行。

+ 先A，A执行一个时间片，步长变为100
+ 再B，执行一个时间片，步长变为200
+ 再C，执行一个时间片，步长变为40
    - 这时算法选择最短行程，于是继续执行C，步长变为80

## 虚拟物理地址
操作系统进行，对进程透明。

我们可以把进程所使用的地址「隔离」开来，即让操作系统为每个进程分配独立的一套「**虚拟地址**」

cpu有两个寄存器：基址寄存器和界限寄存器，帮助虚拟地址落到物理地址上

# 并发
线程和进程的区别

| **比较维度** | **进程 (Process)** | **线程 (Thread)** |
| --- | --- | --- |
| **本质定义** | 操作系统**资源分配**的基本单位 | 操作系统 **CPU 调度**的基本单位 |
| **内存空间** | 互相隔离，每个进程拥有独立的虚拟地址空间 | 同一进程内的线程**完全共享**该进程的地址空间 |
| **独享资源** | 代码、数据、堆、栈、文件描述符等 | 仅独享：**栈 (Stack)**、寄存器、程序计数器 (PC) |
| **通信方式** | 需要借助进程间通信（IPC，如管道、消息队列），复杂且慢 | 直接读写进程的共享内存（如全局变量），简单且极快 |
| **切换开销** | 极大（需切换内存页表等上下文） | 极小（仅保存寄存器和栈指针） |
